### Key lessons (this iteration)
1. **The `page.goto` malformed-URL test was vacuous** — vite's own `viteHtmlFallbackMiddleware` 500s on the bad path before the SPA loads, so it failed identically with/without the guard. The valid non-vacuous proof is the **unit** test (`file-route.test.ts`), mutation-checked. Caught by running the full mutation cycle (neuter → rebuild → confirm-fail → restore); the "confirms-fail identically both ways" tell exposed the vacuity. [[self-hosting-vacuous-pass]]
2. **P20 + CodeRabbit are complementary and agreed on the crash** — P20 found the `decodeURIComponent` bug independently (rated minor; CodeRabbit rated major). Run both; the crash-vector convergence raised confidence.
3. **Fidelity-vs-canon recurs** — the 0.34s duration is the same prototype-value-vs-written-canon tension as BRO-1889's type/icon scale. Resolution: keep the verbatim value, fold into the DS-level decide-once, don't diverge per-component. This is now a rule-of-two (BRO-1889 type/icon + this motion-duration) — if it recurs a 3rd time, the DS reconciliation should widen to "all prototype-vs-written-canon deltas," not just type/icons.
