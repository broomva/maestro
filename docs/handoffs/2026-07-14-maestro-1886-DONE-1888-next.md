## P20 lessons (this ticket)

- The full 4-dimension gate passed at 7/10 with **0 surviving blocker/major** — the 12 findings were all minor/nit. The two most impactful shared ONE root cause: the feed filter was keyed on a merged section's *representative* OrchState (unstable — shifts when the first-in-order sub-state empties while the bucket still holds items), silently dropping the active filter. Fix: key on the **stable plain-voice label** (`toSections` guarantees one section per label via a `Map<label,section>` merge) + a clear-stale effect.
- Fidelity fixes came straight from re-reading the prototype `concepts.css` (not the reviewer's paraphrase): the 720px reading cap + 820px-container grid, and the `[data-view]` body overrides (the attribute wasn't dead — I'd failed to port the rules it keys).
- **Deliberate divergence** (documented, reviewer-approved): board keeps whole-body scroll instead of the prototype's `overflow:hidden` clip — a real board must scroll its work. Filed as **BRO-1887** (Low) for a later per-column-scroll pass.
- Delta re-verify discipline: after fixing an already-passing gate, a **focused Strata-B adversary on the fix diff** (not a full 17-agent re-run) is the proportionate re-check — it confirmed CLEAN, 0 regressions.
- **Rate-limit gotcha:** GitHub GraphQL was exhausted (0/5000) but REST/core had full headroom — CI-status (`commits/{sha}/check-runs`), merge (`PUT pulls/{n}/merge`), and comments all use REST, so the merge was unaffected. `gh pr view/checks` (GraphQL) were the only casualties; do everything via `gh api` REST when GraphQL is dry.
