## Lessons / gotchas this iteration
- **NUL-byte delimiter:** a `.join(" ")`/`.split(" ")` was written with a literal `\0` (NUL) → git treated the file as **binary** + broke Edit exact-match. Fix: python `.replace(b'\x00', b',')`. UUIDs never contain a comma, so `","` is a safe delimiter. (The known "literal NUL → git binary" gotcha, now with the join/split cause.)
- **`vite preview` serves prebuilt `dist`:** the pw config runs `bunx vite preview`, so a **source mutation is invisible until `bun run build`**. Any mutation-proof MUST rebuild between mutate and run — otherwise the test "passes" against stale dist and the mutation proof is vacuous (hit this once; the flush test passed the mutation until I rebuilt).
- **P20 passed but CodeRabbit caught a real functional bug** the workflow missed (stale send-back note resurfacing on reopen) — the two nets are complementary; run both.
- **Formatter-restage:** the pre-commit biome blocked on an unformatted `.locator("header")` chain wrap in chat-m4.pw.ts → `biome check --write` + re-`git add` (the standing lesson).
