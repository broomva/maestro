1. **Any git run in an agent-controlled worktree is a key-exfil surface** — git runs agent-configured drivers/hooks (`diff.external`/`textconv`/`filter.smudge`/hooks) as subprocesses inheriting git's env. Scrub every git spawn's env + `--no-ext-diff --no-textconv` on patch diffs.
