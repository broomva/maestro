## Reusable lessons banked (slice 3)

- **A hand-rolled variant of an existing canonical primitive is a bug surface AND a DRY violation** — reuse
  the seam; if it lives in a module the consumer shouldn't import wholesale, EXTRACT to a shared module
  (`harness/ndjson.ts`) rather than mirror it.
- **An integration test that depends on control-vs-work TIMING flakes in CI even when it passes locally** —
  force determinism with a slow operation (`sleep 2`) that dwarfs the race window, not wall-clock luck.
- **A regression guard whose discriminating power depends on an undocumented runtime detail (stdin chunk
  size) can silently go vacuous** — back every timing/chunking-dependent E2E guard with a deterministic UNIT
  test of the same invariant.
- **GOTCHA rule-of-THREE: the branch-to-main slip happened again (1862).** Make the branch the FIRST action
  after `git checkout main` confirms clean, BEFORE any Read/Edit. Recover via `git checkout -b <b>` +
  `git branch -f main origin/main`. Rule-of-three → candidate hard PreToolUse gate (an L3 change).
