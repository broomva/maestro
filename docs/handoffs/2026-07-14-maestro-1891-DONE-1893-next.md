### Key lessons (this iteration)
1. **P20's design-canon + correctness dimensions catch data-integrity contradictions past green CI + passing tests** — the canceled-rail MAJOR (a fabricated completed progression) is the *third* instance of this exact class (FID-1 badge over-count, FID-4 decodeURIComponent, now FID-5 canceled rail). The cross-model gate is load-bearing for "the derived view silently disagrees with itself."
2. **A ported index map must cover states the prototype's map omitted.** The prototype's `MC_RAIL_INDEX` had no `canceled` entry (→ cur=undefined → all-upcoming); porting it to a total `Record<OrchState, number>` forced a value, and `canceled: 3` (reusing Done) fabricated progress. Lesson: when a port makes a partial map total, the *added* entries need their own correctness check — the prototype's omission was semantically meaningful (all-inert).
3. **§Voice is machine-guardable.** Em dashes + internal build-phase jargon ("P1") in user-facing copy are a recurring drift; a `not.toContain("—") / not.toContain("P1")` guard on the rendered markup catches them.
