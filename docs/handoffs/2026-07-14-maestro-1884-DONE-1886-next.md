## Reusable lessons (this arc)
1. **Staged-vs-working biome trap (cost a CI round):** `biome check --write` fixes the WORKING TREE, but
   `git commit` (no `-a`) commits the STALE STAGED bytes → CI `quality` (biome) fails on formatting the
   local commit "passed". The tell is `git status` showing `MM`/`AM` (staged ≠ working). **FIX: always
   re-`git add` after any `--write` autofix, before commit.** Applied for the rest of the arc.
2. **P20 META again:** the cross-model gate caught a real data-integrity major (badge/tree divergence) that
   green CI + passing tests marked done. Add to the load-bearing P20 rule-of-many.
