```bash
python3 scripts/conformance/test_phase1.py

PATH="$HOME/.cargo/bin:$PATH" cargo fmt --all -- --check
PATH="$HOME/.cargo/bin:$PATH" cargo clippy --workspace --all-targets --locked -- -D warnings
bash -n scripts/conformance/phase1.sh

```

The runner rejects a non-empty evidence directory before writing; a stale `results.json` was
left unchanged in the exit-1 proof. A hook executable and output path containing spaces passed
both a real shell test and `--check-install`. The Python guard tests pass, and removing each of
the new evidence, quoting, shell-restriction or sequence guards makes its test fail. The Rust
quoted-path install test also fails when the shell-aware parser is replaced by whitespace
splitting. See [proofs](2026-11-13/proof-guards/older-threads.txt); other `proof-*` directories
are separately labelled historical negative controls. Formatting, clippy and shell syntax
checks passed; ShellCheck was unavailable.

The runner requires a new or empty `--evidence-dir`, a release binary, Linux `/proc` for
process cleanup, the dogfood skill for Claude or Codex, and a caller-supplied
`GOOGLE_CLOUD_PROJECT` for Gemini Vertex. It never invokes Grok.
